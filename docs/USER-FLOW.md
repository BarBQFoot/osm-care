# My OSM — User Flow

ผู้ใช้หลักคือ อสม. 1 คน ใช้งานข้อมูลประมาณ 10 ครัวเรือน Flow จึงเน้นทางตรงและมีตำแหน่งปุ่มคงที่

## Navigation หลัก

```text
เปิดแอป
  └─ Dashboard
      ├─ ครัวเรือน → Households List → Household Detail
      │                              ├─ แก้ไขครัวเรือน → บันทึก → Detail
      │                              ├─ เพิ่มสมาชิก → บันทึก → Member Detail
      │                              └─ สมาชิก → Member Detail → แก้ไข → บันทึก
      ├─ เพิ่มครัวเรือน → บันทึก → Household Detail
      ├─ พิมพ์เอกสาร → เลือกขอบเขต → Preview A4 → พิมพ์
      └─ ตั้งค่า → ปรับค่าที่มีใน scope → บันทึก
```

## Flow: ค้นหาและเปิดครัวเรือน

1. เปิดเมนู “ครัวเรือน”
2. พิมพ์บ้านเลขที่หรือรหัสครัวเรือนในช่องค้นหา
3. ดูรายการผลลัพธ์และจำนวนสมาชิก
4. เปิดแถว/การ์ดเพื่อดู Household Detail
5. หากไม่มีผลลัพธ์ ให้ล้างคำค้นหรือเพิ่มครัวเรือนใหม่

## Flow: เพิ่มครัวเรือน

1. กด “เพิ่มครัวเรือน” จาก Dashboard หรือ List
2. กรอกบ้านเลขที่และรหัสครัวเรือน
3. กดบันทึก; ฟอร์มแสดง validation ใต้ช่องที่ไม่ผ่าน
4. เมื่อบันทึกสำเร็จ กลับไป Household Detail ของรายการใหม่
5. กดยกเลิกเพื่อกลับหน้าก่อนหน้าโดยไม่บันทึก

## Flow: เพิ่ม/แก้ไขสมาชิก

1. เปิด Household Detail ของบ้านที่ต้องการ
2. กด “เพิ่มสมาชิก” หรือเลือกสมาชิกเดิมแล้วกด “แก้ไข”
3. ตรวจบริบทบ้านที่แสดงแบบอ่านอย่างเดียว
4. กรอกข้อมูลบุคคล/ติดต่อในกลุ่มที่แยกชัดเจน
5. บันทึกแล้วกลับ Member Detail; จากนั้นย้อนกลับไป Household Detail ได้

## Flow: ลบข้อมูล

1. กดลบจากหน้ารายละเอียดหรือเมนูการกระทำ
2. แสดง confirmation ระบุชนิดและชื่อ/รหัสข้อมูล
3. เลือก “ยกเลิก” เพื่อปิด dialog โดยไม่เปลี่ยนข้อมูล
4. เลือก “ยืนยันการลบ” เพื่อดำเนินการและกลับไปหน้ารายการที่เหมาะสม

หากลบครัวเรือนที่ยังมีสมาชิก ให้ dialog ระบุผลต่อสมาชิกอย่างชัดเจนตามกติกาผลิตภัณฑ์ที่ต้องกำหนดก่อน implementation; ไม่สมมติการลบต่อเนื่องเงียบ ๆ

## Flow: พิมพ์เอกสาร

1. เปิด “พิมพ์เอกสาร” จาก Sidebar
2. เลือกขอบเขตข้อมูลที่ต้องการพิมพ์ (ทั้งหมดหรือครัวเรือนที่เลือก)
3. ตรวจ preview และรูปแบบ A4
4. กด “พิมพ์เอกสาร” เพื่อเปิด browser print dialog
5. กลับสู่แอปด้วยปุ่มกลับ/เมนูหลัก

## Flow: ตั้งค่า

1. เปิด “ตั้งค่า”
2. ดูหรือปรับเฉพาะตัวเลือกการแสดงผลที่กำหนดไว้
3. บันทึกและเห็นข้อความยืนยันสถานะ

## เส้นทางกลับและสถานะผิดพลาด

- Breadcrumb และปุ่มกลับพาไปยังบริบทก่อนหน้า โดยเฉพาะจากสมาชิกกลับสู่ครัวเรือนต้นทาง
- Route ที่ไม่พบแสดงข้อความและลิงก์กลับ Dashboard
- Search ไม่มีผลลัพธ์แสดงข้อความเฉพาะและปุ่มล้างตัวกรอง
- ฟอร์มผิดพลาดคงค่าที่กรอกและชี้ฟิลด์ที่ต้องแก้
- Dialog ทุกชนิดปิดได้ด้วยปุ่มยกเลิกและคีย์บอร์ดตามแนวทาง accessibility
